# product-analytics-projects
# Учебные проекты по продуктовой аналитике

Два проекта: анализ пользовательской воронки и анализ A/B-теста.

## Статус

В работе. Подготовлены данные и базовые расчёты.
Следующий этап — проверка данных, визуализация и интерпретация.

## Источник данных

Данные синтетические: сгенерированы для учебной практики.
Они не относятся к Авито или другой реальной компании.

Датасеты и первоначальная заготовка кода подготовлены
с помощью AI. Мои дополнения и выводы описываются отдельно.

## Проект 1. Анализ воронки

Задача: сравнить прохождение воронки мобильными
и десктопными пользователями.

Воронка:
посещение → просмотр объявления → обращение к продавцу.

Объём данных: 12 000 пользователей.

## Проект 2. Анализ A/B-теста

Задача: сравнить конверсию в обращение
в контрольной и тестовой группах.

Объём данных: 16 000 пользователей, по 8 000 в группе.

## Инструменты

Python, pandas, NumPy, SciPy.

## Файлы

- analysis.ipynb — код расчётов
- marketplace_synthetic.csv — данные для анализа воронки
- ab_synthetic.csv — данные A/B-теста
- results.json — рассчитанные показатели

## Ограничения

Проекты демонстрируют методы анализа на синтетических данных.
Результаты нельзя использовать для выводов о реальном бизнесе.
